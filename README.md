# 타임 워프 무쌍 (가제)

시간 왜곡 액션 — **실시간 잠입(1배속) + 턴제 예약 무쌍(2배속)** 하이브리드 게임 프로토타입

> Unity 6 / URP 3D / 탑다운 쿼터뷰

---

## 개요

평소엔 1배속 실시간으로 움직이는 잠입 액션이지만, 게이지를 채워 발동하면 시간이 멈추고 짧은 예약 타임라인 위에 이동·사격·참격을 설계한 뒤 한 번에 재생하는 2배속 무쌍 구간으로 전환됩니다.

- **1배속(실시간, SUPERHOT 모델):** 플레이어가 움직이거나 무기를 쓸 때만 시간이 흐르고, 완전히 멈추면 시간도 정지합니다. 주 무기는 권총(견제/게이지 충전), 검도 쓸 수 있지만 차징이 2배 느립니다.
- **2배속(예약 발동):** 게이지를 소모해 발동하면 시간이 멈추고, 짧은 타임라인에 이동/사격/참격을 순서대로 예약합니다. 실행하면 전부 동시 재생되며, 이 구간의 주 무기는 검(참격)입니다.
- **일섬 판정:** 차징(=피격 노출 구간)과 긋기(=즉발 판정, 체력 무관)를 분리한 것이 핵심 메커니즘입니다. 차징이 길수록 더 멀리, 더 넓게 벨 수 있지만 그만큼 오래 노출됩니다.

자세한 설계 의도는 [`Assets/Scripts/타임워프_실시간_ver v3 기획서.md`](<Assets/Scripts/타임워프_실시간_ver v3 기획서.md>)에 정리되어 있습니다.

## 구현된 기능

### 1배속 (자유 실시간)
- WASD 이동, 마우스 방향 상시 조준(무기 사용/이동 여부와 무관)
- "멈추면 시간 정지" — 적 AI/시야 감지도 함께 멈춤
- **권총:** 마우스를 적 위에 올리면 하이라이트(타겟 지정) → 클릭 시 짧은 조준 대기(즉발 아님) 후 발사. 탄창제(5발), 데미지 기반 처치
- **검:** E 홀드로 차징(최소 4초 / 최대 6초) → 릴리즈 시 그 순간 조준 방향으로 참격. 차징 중 실시간 도달거리 라인 표시. 체력과 무관하게 긋기만 성공하면 즉사
- 하이라이트/사격 판정 모두 **플레이어 위치 기준 실제 시야**로 검증(카메라가 벽 너머를 봐도 캐릭터가 못 쏘면 하이라이트도 안 뜸)

### 2배속 (예약 발동)
- 게이지 보유 시 Space로 발동 → 시간 정지, 탑다운 카메라로 전환
- 우클릭(이동) / 좌클릭(사격) / E(참격)로 최대 3초 타임라인에 행동 예약, Backspace로 취소
- 고스트 위치로 예약 후 캐릭터 위치 미리보기
- Space로 실행 → 순차 재생, 종료 시 자동으로 1배속 복귀(스택 남으면 즉시 재발동 가능)

### 게이지 시스템
- 최대 2스택, 처치 기반 충전(권총/검 무관), 3킬당 1스택 — 수치는 `WarpGauge` 인스펙터 값 하나로 조정

### 체력 시스템
- 플레이어/적 모두 HP 기반 (`PlayerHealth`, `EnemyHealth`)
- 권총은 데미지 누적, 검(참격)은 설계 의도대로 체력 무관 즉사(`Kill()`)
- 플레이어 사망 시 모든 입력 정지 + 시간 정지

### 적 AI
- 상태: Peace / Combat, 시야 센서(각도+반경+장애물 레이캐스트+깜빡임 방지 메모리)
- 발견 즉시 사선 고정, 조준 완료 시 플레이어 피격(데미지)
- 놓치면 마지막 목격 위치로 추적 → 두리번 → 원위치 복귀
- 2배속 실행 중엔 적이 플레이어의 절반 속도로 계속 움직임(비대칭 시간)

### 그 외
- 쿼터뷰 ↔ 탑다운 카메라 자동 전환(예약 구성 중에만 탑다운, 스크롤 줌)
- 플레이어 시야 기반 Fog of War(부채꼴 시야 + 텍스처 베이킹, 현재 씬에서는 비활성화 상태)
- 게이지/타임라인 UI(스택 아이콘, 행동별 색상 블록)

## 아키텍처 메모

- **`IPlayerAction`**(`MoveAction`/`ShootAction`/`SlashAction`) 인터페이스로 2배속 예약 행동을 통일 — `PlayerTimeline`은 구체 타입을 몰라도 `Duration`/`Tick`/`OnEnd`만으로 순차 재생을 처리
- **`IEnemyAction`**/**`ISensor`** 인터페이스로 적 행동/감지 로직을 `EnemyBrain`과 분리 — 새 적 행동(예: 부채꼴 사격 장판)을 추가해도 두뇌 로직은 안 건드림
- 시간 정지 등 횡단 관심사는 `PlayerMovement.IsTimeFrozen`, `PlayerCombat.IsChargingSword/IsAimingPistol` 같은 정적 플래그로 가볍게 공유(이벤트 버스 없이 최소 결합)
- 하이라이트/사격 가능 여부 판정은 반드시 **플레이어 위치 기준 시야**로 재검증 — 카메라(쿼터뷰, 높고 뒤에 위치) 기준 판정만 쓰면 벽 너머를 볼 수 있어 하이라이트-발사 불일치가 생기는 걸 발견하고 수정한 이력이 있음

## 조작법

| 입력 | 동작 |
| --- | --- |
| WASD | 이동 |
| 마우스 | 조준 (항상 마우스 방향을 봄) |
| 좌클릭 | 권총 발사 (적 하이라이트 상태에서) |
| E (홀드) | 검 차징 → 릴리즈로 참격 |
| Space | (게이지 보유 시) 2배속 발동 / (예약 중) 실행 |
| 우클릭 (2배속 중) | 이동 예약 |
| Backspace (2배속 중) | 마지막 예약 취소 |
| 마우스 스크롤 (2배속 중) | 탑다운 카메라 줌 |
