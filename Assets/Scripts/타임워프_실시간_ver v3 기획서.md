# 🎮 [기획서 v3] 타임 워프 무쌍 (가제)

> **버전 노트**
> 
> - **v1 → v2:** 게임 전체를 3초 절대시간 예약제로 돌리던 구조를 폐기. **1배속 실시간(멈추면 시간 정지) + 2배속 게이지 발동 예약**의 3층 구조로 전환.
> - **v2 → v3:** 검을 1배속에서도 사용 가능하게(이원 운용) 하고, 일섬의 판정 메커니즘(차징=노출 / 긋기=즉발)을 확정. 적별 "2배속 정면 차징 가부"를 조준 속도 단일 축으로 정리. 난이도 곡선(무쌍→전략)을 설계 원칙으로 추가. 권총 vs 검 차별화를 탄약 중심으로 정정(소음 근거 철회).

---

## 1. 개요

- **장르:** 시간 왜곡 액션 (실시간 잠입 + 턴제 예약 무쌍의 하이브리드)
- **시점:** 탑다운 쿼터뷰 (LoL, 디아블로 스타일)
- **그래픽 콘셉트:** 스타일리시 미니멀리즘 (URP 3D, 로우폴리 + 네온 이펙트)
- **핵심 타겟:** 피지컬 반사신경 부담 없이, 전략 설계와 화려한 초인 무쌍 연출을 동시에 즐기고 싶은 게이머

---

## 2. v1의 문제 진단과 v2·v3의 방향

### v1(전체 예약제)의 구조적 결함

게임 전체를 고정 길이(3초) 절대시간 예약제로 돌린 결과 두 문제가 드러남:

1. **시야 확보의 어려움** — 멈춘 채로 3초 전체를 미리 예측해야 하니 답답함.
2. **대기(Wait) Padding 문제** — "모퉁이에 1.5초에 도착 → 남는 1.5초 대기"처럼 의도를 억지로 이동+대기로 쪼개는 부자연스러움. 타임라인이 길수록 악화.

원인은 예약제 장르 자체가 아니라 **"게임 전체를 절대시간 예약으로 강제"한 구현 방식**.

### 해법: 예약제를 "2배속 발동 순간"으로 한정

- **시야 문제 해결:** 1배속 실시간으로 돌아다니며 적 배치를 눈으로 파악한 뒤, 원하는 순간에만 예약 모드 진입.
- **대기 Padding 해결:** 예약 시퀀스가 짧고(참격 위주), "이동 후 대기"가 아니라 "누구를 어떤 순서로 베는가"의 설계가 되어 dead time이 거의 없음.

## 3. 핵심 게임 루프 (3층 구조)

```
[1배속 실시간] 잠입 · 권총 견제 · 상황 파악 · 게이지 충전
      ↓ (게이지 충전 완료)
[발동] 시간 정지 + 짧은 타임라인 예약 (설계)
      ↓
[실행] 동시 재생 — 2배속 참격 무쌍
      ↓
[1배속 복귀] 멈춰 있으면 시간 정지 → 재파악 → 스택 남으면 재발동
```

### ① 1배속 (자유 실시간, 멈추면 정지)

- 플레이어가 **움직일 때만 시간이 흐름.** 멈추면 시간도 정지 (SUPERHOT 모델).
- 자유롭게 이동/멈춤. 3초 단위로 쪼개지 않음 → 대기 Padding 없음.
- 멈춘 상태에서는 사고 시간 무한 → **반사신경 부담 없음** (원래 타겟 유지).
- 주 무기는 **권총** (견제·유틸리티·게이지 충전). 검도 사용 가능하나 차징이 2배로 느림 → §5 참조.

### ② 2배속 (게이지 발동 → 예약제)

- 게이지를 소모해 발동. 발동 시 v1의 예약 시스템으로 진입.
- 시간 정지 상태에서 짧은 타임라인에 행동(이동/참격) 예약 → 실행 → 동시 재생.
- 주 무기는 **검(참격).** 무쌍 연출의 핵심.
- **비대칭 시간:** 2배속 중 적은 절반 속도로 계속 움직임. 예약은 "정지한 적을 벤다"가 아니라 **"움직이는 적이 3초 뒤 어디 있을지 예측해서 벤다"**.

### ③ 클리어 연출

- 전체 플레이 입력을 기록 → 클리어 시 정상 속도로 리플레이 (SUPERHOT 방식).

## 4. 2배속 게이지 시스템

- **충전 수단:** 권총 처치 (참격 처치 충전 여부는 §8 열린 과제).
- **최대 2스택:** 게이지를 최대 2회분까지 보유.
- **1스택 = 짧은 예약 창 1회.** 창 길이(초)는 프로토타이핑으로 확정.
- **게이지 양에 따른 참격 강화 없음.** 채웠으면 1회분, 끝. (변수 최소화)

### 창을 짧게 유지하는 이유 (vs Transistor)

- Transistor의 Turn()은 적이 거의 **완전히 멈춘** 상태 → 긴 계획도 성립(예측할 게 별로 없음).
- 본 게임은 2배속 중에도 **적이 transistor보다 빠른 플레이어 절반 속도로 계속 움직임** → 예측 오차가 시간에 비례해 누적. 적들이 소리·시야 등 조건부 행동을 하므로 긴 타임라인은 예측 트리가 폭발 → 찍기가 됨.
- **결론:** 창은 짧게(2~3초 목표). 제약이 아니라 정체성 — 짧기에 발동 타이밍 선택과 1배속 사전 파악의 가치가 올라감.

### 2스택 연속 사용

- 별도 메커니즘 아님. 실행 종료 → 1배속 복귀 → 멈춰 있으면 시간 정지 → 그 상태에서 재파악 후 재발동.
- 정지 상태에서 끊김 없이 반복 가능. 매번 상황이 리셋되어 예측 정확도 유지.
- **전략적 선택:** 1스택씩 아껴 쓰기(안정) vs 2스택 몰아쓰기(큰 무리 일소, 대신 소진 후 위험).

## 5. 무기 메커니즘

### 검 (Sword) — 이원 운용

검은 1배속·2배속 양쪽에서 쓸 수 있으나 **차징 속도가 다름.** 이것이 두 시간대를 하나의 무기로 잇는 축.

- **1배속 검 = 암살 (조건부):** 차징이 2배속 모드보다 2배로 느림. 대놓고 쓰면 적 조준이 먼저 끝나 당함. **적이 아직 나를 인지 못 한 상황(등 뒤·사각)에서만** 유효. 유일하게 면상 검 가능한 적은 저격병
- **2배속 검 = 무쌍 (정면 돌파):** 차징이 절반. 일반병 정도는 정면에서 얼굴에 대고 차징해도 아슬하게 이김. → 2배속의 정체성 = **"평소엔 뒤에서만 가능한 검격을 정면에서 꽂을 수 있게 되는 시간."**

#### 일섬 판정 메커니즘 (핵심)

- **차징 = 노출 구간.** 이 시간 동안만 적이 반응 가능. 적의 조준이 내 차징보다 빠르면 긋기 전에 당함.
- **긋기(일섬) = 즉발 판정.** 발동 순간 범위 내 적은 반응 불가, 즉사. **체력 무관** — 돌격병도 긋기만 들어가면 한 방.
- **범위 = 이동 궤적 + 횡베기 가로 폭.** 얇은 선이 아니라 폭이 있는 띠(band). 적이 완벽한 일렬이 아니어도 궤적 근처에 퍼져 있으면 걸림. → "적을 잇는 선을 정확히 그어야" 하는 부담을 덜고 무쌍의 손맛 확보.
- **차징 시간 = 궤적 길이.** 길게 베려면(다수) 길게 차징 → 그만큼 노출·위험. 다수 처리의 리스크-리턴을 이 단일 규칙으로 표현 (별도 관통 횟수 제한 없음).

### 권총 (Pistol)

- **1배속 주력:** 원거리 견제·저격, 특수 기믹(스위치, 폭발통) 작동, **게이지 충전.** 조준 사격이 빨라 치고 빠지기 가능(암살 단검 같은 운용).
- **2배속 보조 (예측 저격 마무리):** 2배속의 주력이 아님. 일섬으로 다수 정리 후, 사거리 밖으로 튄 소수를 예측 사격으로 마무리하는 용도. 움직이는 적의 미래 위치를 예측해야 하므로 **빗나가면 노출 → 죽음.** 실력자용 고난도 옵션.
- **탄환 순환:** 탄창은 적 드랍. 권총만으로 사살 시 총알이 딱 맞을 정도로만 드랍. 이건 이제 1배, 2배를 나눴으니 더 너그럽게 수정해야할 필요성이 있을지도
- **소음:** 사격 시 **주변**(국지 반경) 적이 위치 인지. 맵 전체가 아님 → 1배속 견제 플레이 성립.
- 탄창 하나당 총알 개수를 적게 제한(5발 정도?)

### 권총 vs 검, 왜 2배속에서 검을 쓰는가

두 무기의 역할이 겹치지 않도록 갈림:

- **권총 = 정밀한 소수 처리.** 탄창 수만큼만 처리 가능(물리적 천장) → 다수 동시 처리 불가.
- **검 = 광역 다수 처리.** 일섬 궤적(띠)에 담기는 다수를 즉발로 동시 정리.
- 따라서 뭉친 다수는 검이 압도적, 흩어진 소수는 권총이 유효. **무쌍(다수 일소)의 판타지는 구조적으로 검만 제공** → 검이 2배속 주인공 자리를 유지.

### 잔여 적 처리 리듬

일섬 후 남은 적 처리는 두 갈래:

- **안전턴(기본):** 남은 적은 일단 엄폐로 회피 → 1배속에서 차분히 권총 견제 / 다음 게이지 충전.
- **욕심턴(실력자용):** 2배속 남은 시간에 권총 예측 저격으로 마무리. 빗나가면 죽음. 강제되지 않는 선택적 깊이.

### 유틸리티

- 수류탄, 연막탄, 디코이 등으로 업그레이드 트리 구성, 플레이 다양성 확보.

## 6. 적 AI 및 난이도

> ⚠️ 적의 반응 속도 서술은 **1배속(권총 플레이) 기준**으로 재해석.
> 

### ① 마지막 확인 위치(Last Known Position) 추적

- 기본은 고정 배치 또는 정해진 경로 순찰.
- 플레이어가 시야에 걸리거나 소리를 내면 '마지막 인지 위치'로 목적지 갱신, 추적 시작.

### ② 소리 유인 (휘파람 시스템)

- 유인 수단(휘파람/발구르기)은 **플레이어의 현재 위치**에서만 발생. 유인하려면 리스크를 감수하고 몸을 노출해야 함.
- 권총 사격 시 패시브로 소음 → **주변**(국지) 적이 위치 인지.

### ③ 예측 사격 및 경계 장판

- 적 AI는 단일 타겟팅이 아닌, 플레이어 이동 방향 앞쪽 격자에 **부채꼴 방사형 사격 장판**을 전개.
- 이미 조준 완료하고 대기 중인 적의 사선(경계)으로 뛰어들면 선딜레이 없이 즉시 탄환 판정 → 소리로 적의 고개를 돌려놓거나, 뒤돌거나, 유틸리티 도구를 활용하는 플레이 강제.

### ④ 적 종류와 2배속 정면 차징 가부

일섬은 긋기만 들어가면 즉사(체력 무관)이므로, 정면 검격의 성패는 오직 **적의 조준 속도 vs 내 차징 속도** 단일 축으로 결정됨. (방패병만 예외 — 물리 면역이라 속도 무관)

| 적 | 정면 차징(2배속) | 결정 요인 |
| --- | --- | --- |
| **일반병** | ✅  성립 | 조준 평균 → 2배속 차징이 먼저 |
| **저격병** | ✅ 여유 | 조준 매우 느림 → 차징 여유. 단 배치에 고지 필요 → 맵 고저차 디자인 검토 |
| **돌격병** | ❌대부분의 경우에 피격 | **날 인지·조준한 상태면** 조준이 빨라 차징 못 버팀. (아직 미인지 상태면 정면 차징 가능) 샷건 특성상 사선 노출 후 즉시 엄폐 안 하면 회피 어려움. 코앞에서 최소한의 차징을 할 시에는 공격 가능. |
| **경계병** | ❌ 즉발 피격 | 이미 특정 방향 조준 완료 → 사선 진입 시 차징 시작 전 피격. 후·측면 취약 |
| **방패병** | ❌ 정면 무효 | 물리 면역, 속도 무관. 무조건 후면 |
- **핵심:** 돌격병이 막히는 이유는 체력이 아니라 **조준 속도**(긋기만 들어가면 한 방). 돌격병·경계병 앞에선 차징 노출을 못 버티므로 측면·후면 우회 강제 → 무지성 방지.
- **방패병 = 유일하게 속도로 못 뚫는 앵커.** 다른 적은 조준 속도 싸움이지만 방패병은 판정 자체가 안 박힘.

### ⑤ 우려되는 문제 (미해결)

- 벽 너머 피킹-사격-후퇴 반복 시 AI 무력화. 수류탄 등 도입 검토.

## 7. 난이도 곡선 (설계 원칙)

적 구성 비율로 게임 전체의 리듬을 만든다. §6-④ 표가 이 곡선의 재료.

- **초반:** 일반병 위주. 2배속 정면 차징이 대부분 통하므로 **무쌍의 쾌감** 중심. 능력의 강력함을 체감시키는 구간. (처음부터 약하면 재미없음)
- **중반 이후:** 경계병·돌격병·방패병 비중 증가. 정면으로 안 뚫리는 적이 섞이면서 **"어떤 적을 정면 처리하고 어떤 적을 우회할지"** 판단이 강제됨 → 전략 부상.
- **원칙:** 처음부터 끝까지 궁극기 남발로 이기면 무쌍이 지루해지고, 처음부터 전략을 강요하면 강함이 안 느껴짐. **무쌍으로 시작해 전략으로 수렴**하는 곡선이 난이도·게임성 양쪽에서 이상적.
- 이 곡선은 순수하게 **적 배치 조합**으로 조절 — 별도 시스템 불필요.

## 8. 열린 과제 (추후 결정)

1. **게이지 충전 기준: 처치 vs 명중**
    - *명중 기반:* 벽 뒤 피킹-사격이 계속 이득 → §6-⑤ AI 무력화 문제 악화 우려.
    - *처치 기반:* 더 건강(리스크 감수 킬 → 검 자원). 단 방패병·돌격병처럼 권총 처치 어려운 적 앞에서 **게이지 순환 막힘** → 해결책 필요.
2. **참격 처치도 게이지 충전할지:** 충전하면 "공격이 공격을 부르는" 선순환으로 **도망 억제**(도망은 순환을 끊는 손해). 단 과하면 궁극기로 궁극기를 채우는 무한동력, 짜면 도망이 이득 → 그 사이 밸런싱 필요.
3. **탄약·게이지 데드락:** 탄약도 게이지도 없으면 아무것도 못 하는 상황 방지 안전장치.
4. **2배속 창 길이(초):** 프로토타입으로 확정.
5. **발동 코스트/리스크:** 게이지 차면 무조건 발동이 최적해가 되지 않도록. (발동 위치 선정 중요성 = 1배속 전략의 핵심 축)
6. **1배속 긴장 유지:** 1배속 이동이 단순 잠입에 그치지 않도록 장치.
7. **2스택 연속 발동 사이 착지 안전:** 실행 종료 위치 + 그 시점 적 사선을 예약 화면에서 미리 보여줄지 (자살을 "운"이 아닌 "판단 미스"로 만들기).

## 9. 진화하는 적 (아이디어)

- 플레이 스타일에 따라 적이 대응책을 준비. 예: 휘파람 후 일망타진을 자주 하면 일부 적이 휘파람에 반응하지 않는 기믹.
- 최종 보스에서 본격 활용 (§10).

## 10. 보스

### 설계 원칙

- 체력이 높아 검격 한 번에 죽지 않음. (일반 적의 즉사 판정과 구분되는 예외)
- 검 피격 시 주위 범위 피해 → 무지성 검격 방지.

### 예시

- **최종 보스:** 주인공과 동일 무장·동속. 전용 AI 필요. "진화하는 적" 설정 적용 — 플레이 스타일 학습(기만↔홀로그램 분신 / 치고빠지기↔복도 피킹 / 검↔배후 검). 구현 난이도 높으면 동일 스펙 전투로 대체(엘든링 화신의 물방울 참고).
- **폭발물 보스:** 폭발 범위가  표시 + 총격 병행(폭발 회피하며 예측).
- **돌진 보스:** 벽을 부수며 일직선 돌진.
- **해커 보스:** 플레이어 장비에 문제를 일으키며 잡몹 뒤에 숨음.

## 11. 스토리 (초안)

**전제:** 사이버펑크. 로우폴리 그래픽에 맞춰 간단한 서사로 몰입 보강. 현재 에셋은 사이버펑크 도시.

**설정 정당화:**

- 플레이어 능력 = 산데비스탄류 초가속. "평소엔 인간, 게이지 차면 순간 초가속" 해석이 v3 구조(2배속=발동형 궁극기)와 가장 잘 맞음. (v1의 투사주법식 "미래 예약" 해석은 예약이 게임 전체가 아니라 2배속 순간에만 걸리므로 부차적으로만 차용)

**줄거리(존 윅형):**

- 과거 기업 병기였으나 탈주/은퇴. 기업이 자산(임플란트) 회수를 위해 추격자 파견.
- 플레이어는 추격을 격파하며 탈출로 향함. 보스들이 자연스럽게 설명됨.
- **최종 보스:** 기업이 제작한 동일 스펙 병기 또는 주인공의 클론.
- **엔딩:** 최종 보스의 임플란트를 반환하는 대가로 추격 중단 → 해피엔드.

## 12. 개발 환경 및 기술 스택

- **엔진:** Unity / **파이프라인:** URP 3D
- **핵심 구현 방식:**
    - **1배속 시간 제어:** "멈추면 정지" 로직이 모든 것의 기반. 이동 입력 유무에 따라 시간 흐름 제어.
    - **2배속 예약:** 기존 v1의 타임라인 UI + 고스트 포지션 시스템을 발동 시 재활용.
    - **일섬 판정:** 차징(노출) 단계와 긋기(즉발 판정, 궤적+가로폭 띠) 단계 분리 구현.
    - **AI 감지:** `NavMeshAgent` + 커스텀 레이캐스트(시야/청각).
    - **비주얼:** `Shader Graph` 네온 잔상 + `Post-Processing`(Bloom, Motion Blur).

### 구현 우선순위

1. **1배속 실시간 이동 + "멈추면 시간정지"** ← 최우선, 모든 것의 기반.
2. 게이지 충전/소모 + 발동 트리거.
3. 발동 시 기존 타임라인/고스트 시스템 연결 + 일섬 판정(차징/즉발).
4. 적 조준 속도 기반 정면 차징 가부 튜닝 → 난이도 곡선용 적 배치.
5. 클리어 리플레이 연출.

### 예상 edge case

2배속 이동중, 혹은 1배속이더라도 적과 충돌하는 경우를 어떻게  처리할 것인가? 1배속은뭐 일반적으로 처리하면 될것같긴 한데, 2배속은 핵심이 행동 예약이다. 예약 경로 중, 공격이 아니라 이동 예약을건구간에서 적과 충돌을 하게 된다면, 그 자리에서 멈추게 하기/계속 실행하기가 있는데…
